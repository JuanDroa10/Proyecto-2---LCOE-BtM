# Proyecto-2---LCOE-BtM
Modelo de dimensionamiento y despacho óptimo (MILP, PuLP/CBC) para sistemas PV+BESS BtM en Colombia bajo regulación AGGE (CREG 174/2021, 1--5 MW). Calcula LCOE bruto y neto para 12 ubicaciones × 19 años × 3 curvas de carga. Datos reales de PVGIS-ERA5, XM y tarifas CREG N2. Adaptado del modelo de P.M. De Oliveira-De Jesus.
